# Home statistics strip design options

These are design previews with illustrative numbers, based on the v140 home page.

- [Option A: four compact statistic cards](home-stats-option-a.png). Equal prominence for captains, players, games played and possible strategies.
- [Option B: featured games count](home-stats-option-b.png). One panel places games played first, with the other statistics alongside it.

Both options retain the existing header, player and captain cards, and footer.
